How to Install Ubuntu Alongside Windows Using Rufus

⏱️ Duration: 45-60 minutes
📅 Updated: January 2025
Intermediate

Learn how to set up a dual-boot system with Ubuntu and Windows, giving you the best of both worlds. This comprehensive guide will walk you through creating a bootable USB drive with Rufus and safely installing Ubuntu alongside your existing Windows installation.

🔧 What You'll Need

USB Drive
8GB or larger (will be formatted)
Ubuntu ISO
Download from ubuntu.com (4GB+)
Rufus Software
Free USB creation tool
Free Disk Space
At least 25GB for Ubuntu
Windows Computer
With admin privileges
Backup Storage
External drive for important files
Important: Always backup your important data before proceeding. While dual-booting is generally safe, there's always a small risk of data loss during partition operations.
1

Download Required Files

First, we need to download Ubuntu and Rufus:

  • Ubuntu ISO: Visit ubuntu.com/download/desktop and download the latest LTS version
  • Rufus: Download from rufus.ie - it's a small, portable application
Tip: Choose the LTS (Long Term Support) version of Ubuntu for better stability and longer support period.
2

Prepare Your System

Before installation, we need to prepare Windows:

  • Backup your data: Copy important files to an external drive or cloud storage
  • Disable Fast Startup: Go to Power Options → Choose what the power buttons do → Change settings that are currently unavailable → Uncheck "Turn on fast startup"
  • Disable Secure Boot: Enter BIOS/UEFI settings (usually F2, F12, or Del during boot) and disable Secure Boot
  • Create free space: Use Windows Disk Management to shrink your main partition and create unallocated space (at least 25GB)
3

Create Bootable USB with Rufus

Now let's create the Ubuntu installation media:

  • Insert your USB drive (8GB+ recommended)
  • Run Rufus as administrator
  • Select your USB device from the dropdown
  • Click "SELECT" and browse to your downloaded Ubuntu ISO file
  • Keep the default settings (GPT partition scheme for UEFI)
  • Click "START" and wait for the process to complete
Warning: This will erase all data on the USB drive. Make sure you've backed up any important files from it.
4

Boot from USB Drive

Time to boot into the Ubuntu installer:

  • Restart your computer with the USB drive plugged in
  • Enter the boot menu (usually F12, F11, or Esc during startup)
  • Select your USB drive from the boot options
  • Choose "Try or Install Ubuntu" from the GRUB menu
  • Wait for Ubuntu to load (this may take a few minutes)
Tip: If you can't access the boot menu, you may need to change the boot order in BIOS/UEFI settings.
5

Start Ubuntu Installation

Once Ubuntu loads, start the installation process:

  • Click "Install Ubuntu" on the desktop
  • Select your language and keyboard layout
  • Choose "Normal installation" and check "Install third-party software"
  • For installation type, select "Install Ubuntu alongside Windows"
  • Ubuntu will automatically detect Windows and show partition options
6

Configure Partitions

This is the most critical step - setting up partitions safely:

  • Ubuntu will show a slider to allocate space between Windows and Ubuntu
  • Drag the slider to give Ubuntu at least 25GB (more is better for development)
  • Review the changes carefully - ensure Windows partitions remain untouched
  • Click "Install Now" only when you're satisfied with the partition layout
Critical: Double-check that you're not accidentally formatting your Windows partition. Look for the Windows partition (usually labeled as NTFS) and ensure it says "no change" or similar.
7

Complete Installation

Finish the Ubuntu installation:

  • Select your timezone and location
  • Create your user account (username, password, computer name)
  • Wait for the installation to complete (15-30 minutes)
  • Remove the USB drive when prompted and restart
8

First Boot and Setup

After restart, you should see the GRUB bootloader:

  • You'll see options to boot Ubuntu or Windows
  • Ubuntu will be selected by default with a 10-second timeout
  • Boot into Ubuntu and run initial updates:
sudo apt update
sudo apt upgrade -y
sudo apt install ubuntu-restricted-extras
9

Install Essential Software

Set up your development environment:

# Development tools
sudo apt install git curl wget vim code

# Media codecs
sudo apt install ubuntu-restricted-extras

# Additional software
sudo snap install discord slack zoom
10

Customize and Optimize

Make Ubuntu work perfectly for your needs:

  • Install GNOME Tweaks: sudo apt install gnome-tweaks
  • Enable additional repositories: Use Software & Updates to enable more sources
  • Set up aliases: Edit ~/.bashrc to add useful command shortcuts
  • Configure Git: Set up your name and email for development work
Pro Tip: Install Timeshift for system snapshots, so you can easily restore your system if something goes wrong during future experiments.
Troubleshooting Common Issues:
• If GRUB doesn't appear: Boot from USB again and run Boot Repair
• If Windows time is wrong: Run timedatectl set-local-rtc 1 in Ubuntu
• If WiFi doesn't work: Install additional drivers from "Additional Drivers" in Software & Updates
Next Steps: Now that you have Ubuntu installed, you can explore Linux development, set up Docker, learn shell scripting, or dive into robotics with ROS (Robot Operating System)!
