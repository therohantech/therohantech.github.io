Python Basics

Getting Started with Python

Python is a powerful, versatile programming language perfect for beginners and professionals alike. Its simple syntax and extensive libraries make it ideal for everything from web development to AI.

What You'll Learn:

  • Variables and data types
  • Control structures (if/else, loops)
  • Functions and modules
  • File handling and error management
  • Object-oriented programming basics

Prerequisites:

No prior programming experience required! Just enthusiasm to learn and a computer with Python installed.

# Python Hello World Example
def greet(name):
    "Function to greet a person"
    return f"Hello, {name}! Welcome to Python!"

# Variables and data types
user_name = "Coder"
age = 25
is_learning = True

# Control structures
if is_learning:
    print(greet(user_name))
    print(f"Age: {age}")
    
# Loop example
for i in range(3):
    print(f"Learning step {i+1}")

Arduino Basics

Hardware Programming Made Simple

Arduino is an open-source electronics platform that makes it easy to create interactive projects. Perfect for robotics, IoT devices, and bringing your digital ideas into the physical world.

What You'll Learn:

  • Arduino IDE setup and usage
  • Digital and analog input/output
  • Sensor integration and data reading
  • Motor control and servo manipulation
  • WiFi connectivity and IoT basics

Hardware Needed:

Arduino Uno board, breadboard, jumper wires, LED, resistors, and various sensors. Complete starter kits are available online.

// Arduino LED Blink with Sensor
int ledPin = 13;
int sensorPin = A0;
int sensorValue = 0;

void setup() {
  // Initialize pins and serial communication
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  // Read sensor value
  sensorValue = analogRead(sensorPin);
  Serial.print("Sensor: ");
  Serial.println(sensorValue);
  
  // Control LED based on sensor
  if (sensorValue > 500) {
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
  
  delay(1000);
}
